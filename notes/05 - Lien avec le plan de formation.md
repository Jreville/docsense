# Lien avec le plan de formation

## Le plan global

- **Durée** : 4,5 mois (7 juillet → 23 novembre 2026)
- **Rythme** : 40h/semaine
- **Budget** : ~200$ (AWS SAA-C03 à 150$, crédits API ~20$)
- **Profil cible** : Platform Engineer with AI, full remote, TJM 650–900€
- **Localisation** : La Réunion → marché national via télétravail

## Phases et timing de DocSense

| Phase du plan | Dates | Ce que DocSense apporte |
|---|---|---|
| **Phase 1 · sem. 1-2** | 7–17 juil | API Anthropic, streaming, tool use (fondations) |
| **Phase 1 · sem. 3-4** | 21 juil–3 août | MVP local fonctionnel, README, GIF démo |
| **Phase 1 · sem. 5-6** | 4–17 août | Mise à jour Malt/LinkedIn, premières candidatures |
| **Phase 2 · sem. 10-13** | sept–oct | Déploiement EKS, RDS, S3, CI/CD GitHub Actions |
| **Phase 2 · sem. 14-16** | oct | IaC Terraform complète, HTTPS en prod |
| **Phase 3** | oct–nov | Stretch (RAG, HPA, observabilité) |

## Certifications en parallèle

- **Anthropic Academy** — "Building with the Claude API" (gratuit, ~8h, certificat) → fait pendant sem. 1-2 et renforce DocSense
- **AWS SAA-C03** (~150$) → passé fin oct, après avoir VRAIMENT déployé DocSense sur AWS. L'exam teste ce qu'on a pratiqué, pas juste lu.
- **Pas de CKA ni CCA-F** → compétences k8s et IA prouvées par les projets, pas les examens

## Pourquoi deux projets ?

DocSense (projet 1) + [[ShipMate]] (projet 2) racontent une histoire :

> "Je sais construire un produit IA **(DocSense)** ET la plateforme pour le livrer **(ShipMate)**."

C'est le profil "Platform Engineer with AI" incarné, pas juste sur un CV.

## ShipMate — rappel

Projet portfolio #2 (construit en phase 2-3) :
- GitHub App + opérateur Kubernetes
- Claude **dans la pipeline CI/CD** : revue de PR, génération de tests, triage d'échecs de build
- Python + Next.js + EKS + Terraform + GitHub Actions
- Le projet le plus différenciant pour le créneau Platform Engineer
